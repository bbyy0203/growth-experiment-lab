# 合成数据生成

本项目所有数据均为代码生成的合成数据，不包含真实用户或公司数据，也不是生产实验
平台。固定配置和随机种子会生成完全一致的数据；更换种子会生成不同样本。

## 输出结构

`randomized` 和 `observational` 各包含三张 Parquet 表：

- `users.parquet`：只含处理前用户属性和历史行为。
- `assignment.parquet`：处理状态、真实分配概率和数据集类型。
- `outcomes.parquet`：实验期点击、观看时长、次日留存和负反馈。

`data/metadata/true_effects.json` 保存配置摘要、实际处理比例、概率 clipping 标记和真实
样本 ATE。潜在结果概率不会写入正式分析表。

真实效果 metadata 只用于合成生成器的回收验证，不被 mart 构建或未来正式效果估计的
默认路径读取。

## 处理前变量

处理前变量包括设备、地区、新老用户、实验前 7 日会话数、观看时长、点击天数，以及
由这些历史活动构造的标准化活跃度分数。`is_new_user` 在实验开始前定义。

## 分配机制

随机实验对每个用户使用同一个配置分配概率，且处理抽样不读取任何协变量或结果。

观察性数据使用处理前活跃度、会话、点击天数、新老用户、设备和地区构造逻辑倾向
概率，并限制在配置区间内。结果模型共享其中部分变量，从而产生可观测混杂。该设计
保留合理 overlap，但不保证任意有限样本中的未调整差异都具有固定大小。

原始 `assignment` 中的 `assignment_probability` 用于记录模拟机制，但在构建正式分析
底表时明确排除。未来倾向得分必须根据处理前协变量重新估计。

结果变量或实验后活跃度绝不能进入倾向模型，否则会造成数据泄漏、调整中介变量或
碰撞变量，并破坏因果解释。

## 结果生成

二元指标先根据处理前协变量构造处理为 0 时的概率，再加入名义处理效应得到处理为 1
时的概率。概率会限制在有效区间，观测结果按用户实际处理状态从对应概率抽样。

观看时长使用两部分模型：先抽取是否产生观看，再对正观看用户抽取非负时长。所有入组
用户都会保留，因此结果中包含零观看用户。

## 真实样本 ATE

二元指标使用最终（包括 clipping 后）的潜在概率计算：

```text
ATE = mean(p1 - p0)
```

观看时长使用每个用户在两个处理状态下条件期望之差的均值。配置中的名义效果只用于
数据生成，不能直接冒充最终真实样本 ATE。

## 当前边界

当前已实现数据生成、SQL 分析底表和随机 A/B 效果评估，但尚未实现观察性 IPTW。
合成结果只能用于验证代码和统计方法，不能外推为真实产品效果。
