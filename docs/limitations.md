# 局限与使用边界

## 合成数据

第一版仅使用合成数据。合成数据可以验证实现能否回收预设效应，但不能证明方法在真实
业务环境中必然有效，也不能替代真实数据质量评估、领域判断或线上实验治理。
生成器中的分布、变量关系和处理效应均为人为设定，不能代表真实产品用户或任何公司。

## 随机实验

后续方法依赖随机分配、实验单位之间近似无干扰、指标口径稳定和 ITT 分析。统计显著
不等同于业务重要，未显著也不证明效果为零。预定义分群只能降低而不能消除异质性分析
中的误判风险。

## IPTW

IPTW 依赖一致性、positivity、正确的倾向模型，以及给定处理前协变量后的无未观测混杂。
它不能修正未测量混杂。极端权重会降低有效样本量并放大方差；权重截断会改变偏差与
方差权衡，不能在看到结果后选择阈值。

## 第一版范围

第一版不覆盖序贯检验、网络效应、复杂随机化、自动分群、双重稳健估计、未观测混杂
敏感性分析或生产部署。任何新增方法都应先明确估计目标和验证策略。

当前阶段尚未实现 A/B 显著性检验、CUPED 或 IPTW 估计。
`assignment_probability` 在合成数据中是已知生成概率；真实观察性研究通常无法直接知道
真实倾向概率，只能在不可检验假设下估计。

当前已实现 DuckDB SQL 分析底表和结构性数据质量检查，但这些检查不能证明业务定义
正确，也不能发现所有语义错误。描述性摘要不构成实验效果或因果结论。

样本量与 MDE 使用大样本正态近似；连续指标规划接口采用共同标准差的两样本近似，不能
替代基于历史或试点数据的分布评估。SRM 通过只表示未发现组别数量异常，不能证明分流
完全正确。SMD 0.10 是经验警告阈值，不是随机化有效性的硬边界。

A/A 假阳性率受有限模拟波动影响，不会精确等于 alpha；偶然超出 95% 二项区间也不必然
表示实现错误。本阶段没有估计当前实验处理效果，也未实现 Bootstrap、CUPED 或 IPTW。
