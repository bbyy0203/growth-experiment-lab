# 局限与使用边界

## 合成数据

第一版仅使用合成数据。合成数据可以验证实现能否回收预设效应，但不能证明方法在真实
业务环境中必然有效，也不能替代真实数据质量评估、领域判断或线上实验治理。

## 随机实验

后续方法依赖随机分配、实验单位之间近似无干扰、指标口径稳定和 ITT 分析。统计显著
不等同于业务重要，未显著也不证明效果为零。预定义分群只能降低而不能消除异质性分析
中的误判风险。

## IPTW

IPTW 依赖一致性、positivity、正确的倾向模型，以及给定处理前协变量后的无未观测混杂。
它不能修正未测量混杂。极端权重会降低有效样本量并放大方差；权重截断会改变偏差与
方差权衡，不能在看到结果后选择阈值。

## 第一版范围

第一版不覆盖序贯检验、网络效应、复杂随机化、自动分群、双重稳健估计、未观测混杂
敏感性分析或生产部署。任何新增方法都应先明确估计目标和验证策略。
