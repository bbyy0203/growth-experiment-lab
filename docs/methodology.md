# 方法说明

## 目标

本文档记录 Growth Experiment Lab 中统计方法的估计目标、假设、适用条件和实现选择。
当前阶段实现合成数据生成，但尚无 A/B 或观察性因果分析结果。

## 合成数据生成

随机实验中的处理以固定概率独立抽取。观察性数据中的处理概率由处理前活跃度、历史
会话、历史点击天数、新老用户、设备和地区通过逻辑函数决定。部分相同协变量也影响
结果，因此观察性数据具有可观测混杂，同时通过概率边界保留 overlap。

三个二元结果分别构造处理为 0 和 1 时的潜在结果概率，并在 clipping 后计算
`mean(p1 - p0)`。观看时长采用含零值的两部分生成过程，真实效果由两个处理状态下条件
期望之差的样本均值计算。潜在概率不会写入正式数据表。

## 随机实验

- 实验单位为用户，按首次随机分组进行 ITT 分析。
- 主指标为次日留存；次要指标为点击与人均观看时长；负反馈为护栏。
- 后续将记录比例差检验、Welch t-test、用户级 Bootstrap、Holm 校正和 CUPED 的公式与假设。

## A/A 模拟

后续将通过有限次数模拟检查检验校准，并使用二项波动区间解释经验假阳性率。

## 用户级分析底表

DuckDB SQL 通过 `user_id` 对 `users`、`assignment` 和 `outcomes` 执行严格一对一关联。
SQL 显式列出字段，避免上游新增生成真值或敏感字段时被自动带入。SQL 结果与 pandas 独立
merge 按用户排序后逐列比较，数值字段使用合理容差，类别和二元值要求一致。

本阶段的摘要仅描述数据质量和总体分布，不比较处理组效果，也不执行显著性或因果推断。

## 观察性因果分析

第一版目标是 ATE，主要方法为 stabilized IPTW。倾向模型仅可使用处理前变量。
后续将记录 overlap、positivity、平衡、极端权重、有效样本量和 Bootstrap 方案。
当前阶段只生成供未来方法使用的数据，不执行 IPTW 估计。

## 可复现性

所有随机过程必须从配置中的固定种子派生。所有报告数字必须由代码执行产生。
