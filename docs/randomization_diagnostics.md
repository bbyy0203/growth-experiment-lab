# 随机化质量诊断

诊断仅适用于合成 randomized mart，不对 observational 数据运行 SRM，也不估计处理效果。

## SRM

Sample Ratio Mismatch 使用卡方拟合优度检验比较实际组别人数与预期分流人数。默认阈值
为 0.001。SRM 通过只表示未发现明显人数异常，不能证明随机化完全正确，也不能替代
协变量平衡检查。

## 处理前平衡与 SMD

连续变量使用处理组与对照组均值差除以合并标准差；二元变量使用合并 Bernoulli 标准差；
设备和地区逐类别水平构造指示变量，不比较类别编码均值。

绝对 SMD 超过 0.10 产生经验警告，但不直接判定实验无效。平衡诊断主要关注差异幅度，
不使用 `p > 0.05` 证明两组相同。只允许文档列出的七个处理前协变量，点击、观看时长、
次日留存、负反馈及其他处理后变量均禁止进入诊断。

## A/A 模拟

A/A 使用独立固定种子生成真实效应为零的合成数据。处理独立于处理前活跃度；活跃度可
影响个体留存概率，但 treatment 不影响留存概率。每次模拟重新随机分组，并运行双侧
两比例 z 检验。

经验假阳性率不会精确等于 alpha。报告提供 Monte Carlo 标准误和基于二项分布的 95%
波动区间；偶然超出该区间产生警告，但单次超出不必然表示代码错误。

## 禁止信息

诊断不读取 observational mart、真实分配概率、潜在结果、真实处理效应或
`true_effects.json`。输出只包含设计参数、随机化诊断和独立 A/A 摘要。
