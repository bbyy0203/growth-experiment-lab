# 实验设计

本项目使用合成数据，是个人开源作品集，不是公司生产实验平台。实验设计输出是前瞻性
规划结果，不是当前实验的处理效果。

## 核心概念

- `alpha`：在零效应成立时错误拒绝零假设的目标概率。
- `power`：在设定效果成立时检出该效果的目标概率。
- MDE：在给定 alpha、power 和样本量下计划检测的最小效果。
- 分流比例：计划分配到处理组与对照组的用户比例。

主指标为二元 `next_day_retention`。默认 MDE 0.01 表示绝对增加 1 个百分点，不是相对
增加 1%。相对提升作为 `absolute MDE / baseline` 补充报告。

## 二元指标

样本量使用两独立比例的 Cohen's h 与 statsmodels `NormalIndPower`。输出分别列明对照组、
处理组和总样本量，结果向上取整。给定实际组别人数时，在 `0` 到 `1 - baseline` 的有效
概率边界内使用二分搜索反解 MDE。

样本量规划必须在查看实验结果前完成。根据观测结果反复修改 alpha、MDE 或目标功效会
破坏预先声明的推断口径。

## 连续指标接口

连续指标接口使用预期均值差除以试点标准差得到标准化效应，并采用两样本 t 检验规划
近似。真实业务应使用实验前历史数据或独立试点估计标准差，不能使用当前实验的处理后
观看时长来反向规划。

## 数据边界

规划只读取配置和 randomized mart 的实际组别人数，不读取结果均值、真实处理效应、
`assignment_probability`、潜在结果或 `true_effects.json`。
